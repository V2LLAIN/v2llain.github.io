  TOP SECRET — 작성 안내 (홈페이지 "Off the Record")
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 사건(case) 하나 = 폴더 하나
  Top secret/case-00/   → CASE #000
  Top secret/case-01/   → CASE #001
  Top secret/case-02/   → CASE #002  (새 폴더를 만들면 책갈피가 자동으로 하나 더 생깁니다)
  폴더 이름의 숫자 순서대로 책갈피가 쌓입니다.

■ case.txt  (책갈피를 누르면 나오는 문서)
  맨 위 몇 줄은 문서 정보입니다. 필요 없는 줄은 지워도 됩니다.
    TITLE: 책갈피·문서 제목 (영문 대문자 추천)
    SUBTITLE: 한 줄 부제
    DATE: 날짜
    STATUS: 상태 (예: OPEN, CLOSED, ONGOING)
    LEVEL: 보안 등급 (예: EYES ONLY ⏵ NOFORN ⏵ ORCON)
    CODENAME: 작전명
    LOCATION: 장소
  그 다음 줄에 --- 를 쓰고, 그 아래에 본문을 자유롭게 씁니다.
  - 줄바꿈은 그대로 보이고, 빈 줄은 문단을 나눕니다.
  - [[가릴 내용]]  → 검은 줄로 가려졌다가 마우스를 올리면 보입니다.
  - **굵게**       → 굵은 글씨
  - 유튜브 영상:   VIDEO: https://youtu.be/영상주소
  - 외부 사진:     IMAGE: https://사진주소.jpg
  - 링크:          LINK: https://주소
  - 본문 속 주소:  https://주소 를 그대로 쓰면 "link ↗" 로 보이고, 누르면 그 주소로 갑니다.
                   [보여줄 글자](https://주소) 처럼 쓰면 원하는 글자로 보입니다. 예: [댄스 영상](https://youtu.be/...)

■ 사진·영상 (증거물 EXHIBIT)
  같은 폴더에 jpg, png, gif, webp, mp4, webm 파일을 올리면 자동으로 문서 아래에 붙습니다.
  파일 이름 순서대로 EXHIBIT A, B, C ... 가 됩니다.
  (아이폰 HEIC 사진은 브라우저에서 안 보이니 jpg로 바꿔서 올려 주세요. 영상은 100MB 미만으로.)

■ AGENT 폴더 (폴더 안쪽 표지에 클립으로 꽂힌 "AGENT ???")
  Top secret/AGENT/ 는 사건이 아니라 요원 신상 파일입니다. 책갈피로 나오지 않습니다.
  - agent.txt : 신상 파일 글 (case.txt와 같은 방식. TITLE / CODENAME / STATUS / LEVEL / --- / 본문)
  - 사진 파일들 : 신상 파일 아래에 부채꼴로 놓이는 사진. 파일 이름 순서대로 놓이고,
                  누르면 화면 위로 날아올라 사건 사진처럼 쫙 깔립니다.
                  (파일 이름 앞의 숫자는 순서용이고, 나머지가 사진 설명이 됩니다. 예: "04 chess.jpg")

■ 세계지도 (예: case-03)
  case.txt 본문에 아래처럼 쓰면 문서에 세계지도가 생기고 도시마다 핀이 꽂힙니다.
    HQ: 서울 | 37.5665, 126.9780                                  ← 출발지(본부). 빨간 점선 항로가 여기서 출발
    PIN: 이스탄불, 터키 | 2010 | 41.0082, 28.9784 | istanbul.jpg   ← 도시 | 연도 | 위도, 경도 | 사진 파일
  - 사진 파일은 같은 폴더에 올리면 됩니다. 핀을 누르면 그 도시 옆에 사진이 뜹니다.
  - 사진이 아직 없으면 "PHOTO CLASSIFIED" 로 표시됩니다.
  - 위도·경도는 구글 지도에서 장소를 우클릭하면 맨 위에 나오는 숫자를 그대로 붙여 넣으면 됩니다.
  - 지도는 핀들이 다 보이도록 알아서 확대됩니다.
